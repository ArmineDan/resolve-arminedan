Follow this loop strictly:
1. **Explore**: Analyze requirements and existing code.
2. **Plan**: Formulate a concise step-by-step plan.
3. **Implement**: Apply code changes.
4. **Test**: Run tests to verify changes.
5. **Summary**: Provide a short wrap-up.
